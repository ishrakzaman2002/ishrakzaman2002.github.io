Selected work

FIG.01

Self-Checkout+

CV & AI LEAD · SENIOR CAPSTONE

FALL 2025 – MAY 2026

A barcode-free autonomous grocery checkout system. Dual cameras identify each item as it's placed on the belt, a conveyor moves it through checkout, and a receipt is emailed automatically once the transaction closes, no scanning required.

STEP_01
Detect
YOLOv8 handles real-time item detection from a dual-camera feed.
STEP_02
Match
CLIP visual embeddings and FAISS vector search identify the item against a 1,007-SKU catalog built from GroZi-120.
STEP_03
Checkout
FastAPI and a React UI on a Pi 5 confirm the item; ultrasonic sensors and an ATmega328p drive the conveyor, then SMTP emails a receipt.
TOP-1 ACCURACY100% across 16 SKUs
CHECKOUT TIME<6s end-to-end
UPTIME12+ hrs · 0 crashes / 100 trials
HARDWARE COST<$435
YOLOv8 CLIP FAISS FastAPI SQLite React Raspberry Pi 5 ATmega328p
